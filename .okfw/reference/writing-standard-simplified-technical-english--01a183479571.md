# Writing standard: Simplified Technical English

All text in this wiki obeys these rules. They come from ASD-STE100 Simplified Technical English. The rules make the text easy to read for people and for AI agents. They also make the text easy to translate.

## Words

1. Use one word for one meaning. Use the approved terms in [Glossary: approved terms](/reference/glossary-approved-terms--01a183479576.md).
2. Use the simple form of a word. Write "use", not "utilize". Write "start", not "initiate".
3. Use a technical name only if [Glossary: approved terms](/reference/glossary-approved-terms--01a183479576.md) approves it. Add a new term to the glossary before you use it.
4. Do not use idioms, slang or jokes.
5. Write "must" for a requirement. Do not write "should" for a requirement.
6. Use an abbreviation only after you give its full form once on the page.

## Sentences

7. Write one topic in one sentence.
8. A procedure sentence has 20 words or fewer. A descriptive sentence has 25 words or fewer.
9. Use the active voice. Write "The Release Actor promotes the image", not "The image is promoted".
10. Use the present tense for facts. Use the past tense only for history.
11. Write the subject and the verb close together.

## Procedures

12. Write one instruction in one step.
13. Start each step with a verb in the imperative: "Run", "Open", "Verify".
14. Write a warning before the step it applies to, not after it.
15. Put a command in a code block. Explain it in the step text.

## Paragraphs and concepts

16. A paragraph has one topic and six sentences or fewer.
17. A concept has one idea. Split a concept when it has two.
18. The `description` is one sentence of 25 words or fewer. It states what the concept is and when to read it.
19. Keep facts from a source apart from your conclusions. Put a conclusion under its own heading, for example "## Analysis".

## Checks

Before you save a concept:

- Read each sentence. Is it shorter than the limit?
- Find each passive verb. Change it to active.
- Find each term. Is it in [Glossary: approved terms](/reference/glossary-approved-terms--01a183479576.md)?
